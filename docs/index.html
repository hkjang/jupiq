FAQ

자주 묻는 질문

인터넷이 없는 망에서도 운영할 수 있나요?

네. 릴리스의 jupiq-v1.4.3.tar.gz를 반입해 docker load로 설치합니다. 런타임에는 접근 가능한 PostgreSQL과 네 환경변수만 필요하며 외부 CDN이나 SaaS에 의존하지 않습니다.

망이 끊기면 중앙 화면도 멈추나요?

아닙니다. 해당 Hub를 Degraded로 표시하고 마지막 성공 snapshot을 유지합니다. 다음 고정 수집 주기에 다시 시도하며 다른 Hub 수집은 별도 goroutine에서 계속됩니다.

Notebook 코드나 프롬프트를 수집하나요?

Hub·자원 수집기는 코드·셀 내용·출력·LLM 프롬프트·응답 본문을 수집하지 않습니다. 다만 AI 채팅에 직접 입력한 메시지는 응답 생성을 위해 설정된 Provider로 전달됩니다.

GPU 모니터링 없이도 쓸 수 있나요?

네. GPU 모니터링은 초기 기본 OFF이며 JupyterHub 사용자·서버·카탈로그·감사 기능과 독립적입니다. ON 전에는 Prometheus와 DCGM 지표를 확인하세요.

Keycloak이 장애 나면 어떻게 하나요?

OIDC 상태를 진단하고 감사 가능한 Bootstrap 관리자 계정으로 긴급 접근할 수 있습니다. 운영에서는 강한 초기 비밀번호, 제한된 접근 경로, 즉시 비밀번호 변경 정책을 적용하세요.
